# Orden visual de fotos

El orden de fotos debe cambiar dentro del modal sin recargar ni cerrar la edición.

- Una sola foto: no mostrar flechas ni número de posición.
- Dos o más: mover visualmente con flechas y actualizar números.
- Las flechas no escriben en base de datos.
- `Guardar producto` persiste el orden pendiente en `product_images.sort_order`.
